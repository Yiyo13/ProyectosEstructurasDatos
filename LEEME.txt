Eclipse:
  File > Import > Existing Projects into Workspace > seleccionar esta carpeta.
  Ejecutar com.proyecto.mvc.models.Main

  java -cp bin com.proyecto.mvc.models.Main

Datos: flights.json, trips.json, airports.json (se crean solos si no existen).
